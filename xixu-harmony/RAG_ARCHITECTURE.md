# 汐序 Agent 本地混合 RAG v2

汐序先在设备本地检索课程、课表、任务和笔记，只把与当前问题有关的片段交给 DeepSeek。检索层不依赖云端向量数据库，也不会为了检索额外发送一次模型请求。

## 检索流程

1. 将课程、实际教学周排课、任务、笔记与碎片转换成只读检索文档，保留稳定的 `documentId` 和 `chunkId`。
2. 长文按原始正文的自然标点与换行切块，片段最多 560 个字符、重叠 80 个字符。切块覆盖到正文最后一个字符；不改写、压缩或截断保存的原文。
3. 索引缓存在内存，复用未改变文档的分词、片段与特征。逐字段检查正文、标题、课程关系、日期、状态和图片数量；即使来源 ID 与更新时间不变，正文修改也会让对应文档失效。删除的文档会从索引移除。
4. `await prepareAgentRagIndex()` 分批准备索引，每 24 个文档或 64 个片段让出主线程；同步 `semanticAgentSearch(query)` 保留兼容并再次核对来源变化。统计信息包含索引版本、复用/重建文档数量与让出次数。
5. 从原问题识别资料类型、任务类型、状态和日期，不能从同义词扩展后的文本推导意图。支持“功课”“还没做完”“这礼拜三”、中文数字年月日等常见语音表达；无效日期不会自动滚入下个月。
6. 明确的日期和完成状态先作为硬筛选：任务按事项日期/截止日期、笔记与碎片按最后更新日期、课程按实际教学周日期。不会把作业的预留学习日期当作截止日期。“最近笔记”查过去 30 天，“近期待办”查接下来 21 天。
7. 去掉提问套话和停用词，再用精确标题、关键词与 BM25 风格全文评分召回。短指代追问可借用本会话上一条用户问题的主题词，但不继承旧日期或状态，不借用其他会话。辅助检索问题不替换用户原句或写操作解析。
8. 本地特征哈希只辅助有词汇证据的候选重排。类型、新近程度或哈希碰撞不能单独召回无关内容；找不到相关资料时返回空数组并标明 `no-relevant-sources`。
9. 不同来源优先，再用最大边际相关性降低重复；同一文档最多两个片段。根据查询复杂度最多 6、8 或 12 条上下文，总正文严格限制在 6400 个字符内。
10. 交给模型的每条上下文包含原始来源编号，以及 `excerpt.start/end/sourceChars/partial/budgetTruncated`，明确说明是否只提供片段或因请求预算截片。最近对话保留有限请求窗口，更早对话生成请求内摘要；保存的原始对话不因请求窗口被删除。

## 本地向量的准确含义

当前实现是 384 维词汇特征哈希，不是学习得到的语义 Embedding，也没有 Chroma 等外部向量数据库。检索信息明确标注 `featureModel: local-token-hash-not-embedding`。显式词汇别名和中文字符 n-gram 能覆盖一部分常见说法，但不能保证理解任意语义改写。需要真正的语义召回时，应另行评估设备端 Embedding 模型、存储成本与隐私边界。

## 图片与来源保护

图片仍随原笔记保存，检索上下文只包含图片数量；此层不上传图片、不自动 OCR、不创建虚构的图片文字。所有缓存都属于可重新生成的检索投影，搜索与索引准备不会写入笔记、任务、课程或原始聊天记录。未提供的华为备忘录原件不会被擅自迁移。

## 安全边界

- RAG 只决定提供给模型的只读上下文，不直接修改数据。
- 新增、完成、规划和追加内容必须显示预览并由用户确认。
- 删除任务、笔记或课程会显示目标和影响，并要求单独确认。
- 检索在本机完成，DeepSeek 只收到最终选中的文本片段。

## 后续扩展

本地特征哈希接口可以替换为经过评测的设备端 Embedding 模型，而来源编号、结构化过滤、重排、上下文预算和安全执行层可继续复用。当前缓存为进程内缓存，不持久化用户资料副本；更大资料量可进一步评估索引持久化、真正的语义召回和精确候选倒排索引，但不能只依赖更新时间判断正文是否变化。

## 回归验证

`work/check-rag-v2.cjs` 使用隔离 VM 与合成数据，检查同 ID 编辑失效、索引复用、无关空结果、通用标题不误召回、日期/状态硬筛选、语音日期、当前会话追问、长文末尾与原文保护、来源多样性、片段偏移、上下文预算及异步让出。`work/check-rag.cjs` 保留浏览器到请求上下文的集成回归。这些测试不等同于已验证用户的 74 条原始华为备忘录或鸿蒙手机实际帧率。
