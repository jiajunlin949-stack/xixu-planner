# 五分钟演示：无需私人资料或外部数据库

本演示使用自行输入的合成内容。请使用新的浏览器配置或无痕窗口，不在存有真实笔记的环境测试恢复/导入功能。

## 1. 启动

在仓库根目录运行（Node.js 22、Windows PowerShell）：

```powershell
npm ci
npx playwright install chromium
node work/prepare-native.cjs
node work/serve-native-preview.cjs
```

打开 `http://127.0.0.1:8767/`。端口仅监听本机；若已被其他实例占用，先核实原服务用途，不要强行结束不明进程。

无需Docker、Milvus、模型Key或真实个人资料即可演示以下本地功能。网页里没有手机原生桥接，不能据此演示真实联网模型/OCR/系统提醒。

## 2. 日程：预览 → 确认 → 撤销

进入设置中的“汐序 Agent”，输入：

> 帮我添加任务：明天下午三点完成合成演示

核对待确认事项的标题、日期和时间：确认前不应出现在日程中。确认后查看日程，再使用撤销检查可逆性。这里的确定性解析不需要模型请求。

## 3. 备忘录：保留原文

输入：

> 帮我记下来：演示想法：把复杂作业拆成几个小步骤。

核对正文后确认。进入备忘录检查正文及上次编辑时间。再提出与刚才内容有关的问题，查看本机检索到的来源，点击返回原文。无模型Key时应显示检索/规则结果，不应宣称生成了联网模型回答。

## 4. 时间与会话

- 输入“帮我添加任务：周三18:00联系测试老师”，选择本周或下周，检查标题和时刻仍被保留；确认前不写入。
- 发送“明天考试几点？”：这是查询，不应新建考试。
- 建立第二段对话，在两段会话分别写草稿并切换，检查草稿独立。
- 添加合成课程后，可按“某月某日某课程1-2节调到另一日3-4节”的格式演示调课预览、确认和撤销。不确定的日期或目标应先澄清，不猜测课程。

## 5. 自动化验证

```powershell
npm run ci
```

公开套件预期执行43步（41个回归脚本+2项生成），不需要真实资料和外部模型Key。输出报告在 `outputs/ci/summary.json`；合成PDF由脚本生成。

工程测试、网页演示、真实模型连接和鸿蒙真机验收是四个不同证据层级。完整范围与限制见 [需求验收](PROJECT_STATUS_AND_PLAN.md) 和 [版本记录](../CHANGELOG.md)。
