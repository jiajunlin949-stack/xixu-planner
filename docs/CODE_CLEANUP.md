# Agent 代码审查与职责清理（2026-11-01）

2026-11-02 补充：针对公开回归失败完成运行时修复与测试流程迁移。默认对话在异步摘要前登记，仍保留会话删除与资料替换校验；明确记录笔记会清理旧事项追问；检索命令优先于截止关键词。聊天回复保留输入节点、草稿及阅读位置，底部阅读可跟随新回复；确认保存恢复反馈动效。

后台资料入队合并为单一队列，交互请求优先；普通笔记不再逐条建立无意义任务，已追踪资料的取消和更新仍会检查。原有三个轮询合并到一个前台时钟。原件阅读恢复安全链接入口，检索来源保留有界命中理由。生成脚本统一资源换行并规范化共享 JSON，避免无业务意义的产物差异。

下方保留此前的审查与清理记录。本轮验证范围见 [开发与验证记录](VALIDATION_STATUS.md)。

## 审查发现与处理

| 发现 | 处理 | 代码入口 |
| --- | --- | --- |
| 运行模块混合调度、消息卡、工作台和事件处理 | 按职责拆成 runtime / results / workbench，manifest 保留明确组合顺序 | 三份 `assistant-*.js` 模块 |
| 全局 `agentPending`、`agentRequest` 需要手动同步，难以覆盖独立图片/模型请求 | 删除旧别名与同步包装器，备份/历史恢复入口直接计算当前工作状态 | `assistantAnyWorkBusy` |

| 结果因原消息移除/编辑而丢弃后，任务仍可能停在“待确认” | 当前报告被丢弃时结束其待处理状态；旧报告不能结束已续接的新执行批次 | `acknowledge`、Outbox 的 assignmentId |
| 日程确认直接从界面层改写任务领域字段 | 引擎提供纯 `prepareConfirmation`，由原日程事务一次保存，保留统一回退边界 | engine / core / results |

# Agent 重复路径清理（2026-10-30）

本次只编辑源码，没有运行应用、编译、测试或 CI。减少重复实现不等于已测得性能提升。

## 移除的旧路径

- `agent.js` 中被新监听器覆盖的发送链、固定 DeepSeek 请求载荷、全局回调复用和旧直接写入执行分支。发送由 `assistant-network.js` 负责；写入统一经过 `assistant-core.js` 的变更预览、版本检查和事务记录。
- `ai-assistant.js` 中已被覆盖的旧模型设置页、连接测试、旧 Key 按钮。设置由统一模型网关负责；智能速记和图片核对使用消息数组及明确的结果接收函数。
- 原生 `Index.ets` 中已经停止承载请求的 `DeepSeekBridge` 及 `XixuAI` 注册、无用导入。`ModelGateway` 仍保留旧 DeepSeek Key 的迁移读取，不删除用户已保存的密钥。
- 两套电脑 JSON 请求/取消逻辑合并到 `knowledgeCall` / `cancelKnowledgeRequest`。移除旧自动聊天包装器，保留后端兼容 API、配对、来源核对和显式同步。
- 被重复覆盖的本地规则函数、无实际作用的字段读取包装器和无法进入的弹层字段恢复分支。

## 保留的内容

课程互换与单节调课、会话与草稿、手动导入、原件、图片、时间信箱、变更记录、已有密钥及个人资料都保留。`agentContext` 被检索契约脚本使用，不能仅凭生产入口变化认定它无用。原生 `rawfile/app.js` 是打包资源，仍通过文本组合同步。
